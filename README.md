# AndroidBox.cz Plugins

Veřejný distribuční repozitář pluginů pro AndroidBox.cz.

## Pluginy

- AndroidBox.cz Site Manager — 4.2.2
- AndroidBox.cz Affiliate Manager — 1.1.1

Soukromý repozitář `Androidbox.cz` zůstává hlavním vývojovým repozitářem. Tento repozitář obsahuje veřejné distribuční kopie pluginů, release ZIPy a update manifest.

## Automatické aktualizace

Pluginy používají vlastní update kanál přes `update.json`. WordPress kontroluje dostupnou verzi a při nalezení novějšího balíčku nabídne standardní aktualizaci.
